One line about office life, under 200 characters: a company-wide plea to end reply-all, answered by 214 people replying all to agree. A judge model compares the jokes pairwise on whether the line is a real joke, turns somewhere unexpected, rings true about the office, stays tight, and brings a fresh take.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

That writes exactly one line — the joke — to `/tmp/out/entry.txt` (98 characters). Pure Python standard library, deterministic, no network, no input files.
